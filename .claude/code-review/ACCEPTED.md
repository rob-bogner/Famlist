# Akzeptierte Befunde

Was hier steht, meldet der tägliche Review nicht mehr. Eine Zeile pro Eintrag:

`- <Befund-ID oder Datei:Symbol> – <kurzer Grund> (<Datum>)`

Die Befund-ID steht im Report in der ersten Spalte (z. B. `DEAD-DS`).
